# AI VOC Analyzer

[발표자료 PDF 다운로드](https://github.com/Kimminsun8220/VOC-Analyzer/raw/refs/heads/master/outputs/presentation/VOC_Analyzer_발표자료_5장_텍스트.pdf)

VOC 입력 → AI 분류 기준표 초안 → 검토·확정 → 고객 의견 자동 분류 → 기준 수정 → 변경된 기준으로 다시 분류 → 시각화를 연결한 로컬 Streamlit 앱입니다.

화면과 차트의 글꼴은 **프리텐다드**입니다. [공식 배포본 v1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard)의 가변 글꼴을 `static/fonts/`에 포함해 외부 폰트 서버 없이 제공합니다. 사용 조건은 함께 포함한 `static/fonts/OFL.txt`에서 확인할 수 있습니다. 실행 중에 글꼴 설정을 변경했다면 앱을 다시 실행하고 브라우저를 새로고침합니다.

## 실행과 첫 분석

`voc-v8`은 초안 생성 → 자동 검사 → 별도 AI 품질 검토 → 재검사 → 초안 저장 순서로 코드북을 만듭니다. 같은 계층의 추상화·분류 관점·상하위 포함 관계·중복·과세분화·경계·기타 반복 주제·원문 근거를 검토합니다. 혼동 가능한 코드의 포함·제외 기준은 기존 `definition`에 기록하고, 검토 근거와 처리 내용은 기존 변경 이력에 보존합니다. Code/Issue 저장 구조와 사용자의 확정·리코딩 절차는 유지합니다.

기타 비중 10~15%는 재검토 신호이며 목표나 강제 상한이 아닙니다. 10% 이상이면 기타의 반복 주제도 검토하지만, 반복성과 별도 해석·대응 가치가 함께 있어야 새 코드를 제안합니다. 타당한 추가 코드가 없으면 기타가 높아도 분류를 완료할 수 있습니다. 맞는 코드가 없는 의견·해석 불가·승계 검토는 계속 미해결로 남습니다. 분모는 전체 응답 수, 분자는 기타를 포함한 고유 VOC 수입니다. 엄격한 개별 주제 1% 기준은 없습니다.

자동 검사는 빈 필드·원문 근거·감성 명칭·명시적인 동의어/중복·다른 대분류에 반복된 세부분류명을 확인합니다. 의미 경계·일반화·추상화·분류 관점·분석 가치는 AI가 판단하므로 정확도를 자동 보증하지 않습니다. 기존 사용자 편집에는 새 AI 전용 규칙을 소급 강제하지 않습니다. 주제와 감성은 분리하고, 복합 VOC의 독립 주제는 여러 의견으로 기록합니다. 기존 초안을 변경하려면 새 초안을 생성해 검토·확정하고 새 분석을 시작합니다. 이전 결과는 보존됩니다.

Python 3.14 환경에서 확인했습니다. 프로젝트 폴더의 PowerShell에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

[앱 열기](http://127.0.0.1:8501)

1. **1. 입력**에서 고객 의견을 직접 붙여넣거나 CSV·XLSX 파일을 업로드합니다.
2. 본문 열과 선택 사항인 분석 배경을 확인한 뒤 **입력 데이터 확인 → 입력 저장 → 분류 기준표로**를 누릅니다.
3. **자료 설명과 분류 요청 (선택)**에 조사 상황이나 원하는 분류 방향을 적고 **AI로 분류 기준표 만들기**를 누릅니다. 표에서 대분류·세부분류·정의를 고치거나 행을 추가·삭제할 수 있습니다.
4. **분류 기준표 저장 → 이 기준표로 VOC 분류하기**를 누릅니다. 저장한 기준표로 고객 의견을 분석한 뒤 결과 화면이 열립니다.
5. **3. 분류 결과**에서 대분류·세부분류와 전체 감성 비중을 확인합니다. 차트 행을 끌어 놓아 합쳐 보고, 원문 표의 분류·감성 셀을 더블클릭해 수정합니다. **VOC별 분류 다운로드**와 **분류 통계 다운로드**에서 Excel을 받습니다.

초안과 확정본 모두 표의 셀을 눌러 직접 수정합니다. **행 추가**로 새 분류를 넣고 행 오른쪽 메뉴의 **행 삭제**로 제거할 수 있습니다. 코드 ID는 자동으로 유지하므로 편집 표에서 숨겼습니다. 변경은 **분류 기준표 저장**을 눌러야 저장됩니다.

대분류·세부분류 열 제목의 필터 표시를 누르면 검색·체크박스 복수 선택·전체 선택으로 표시할 값을 정하고 **적용**할 수 있습니다. 두 열을 함께 적용하면 두 조건에 모두 맞는 행을 보여줍니다. 필터를 적용해도 숨겨진 행은 저장할 전체 기준표에 유지합니다. 필터 중인 열은 표시가 바뀌고 표 아래에 표시 개수와 **필터 해제**가 나타납니다. 이름을 편집 중인 행과 추가·분리·통합으로 편집할 새 행은 다음 필터 적용까지 화면에 유지합니다. 새 버전을 저장한 뒤에도 현재 필터 범위에서 계속 편집할 수 있습니다.

확정한 기준표도 **2. 분류 기준표**의 표에서 바로 수정합니다. 왼쪽 손잡이를 다른 행에 끌어 놓으면 대분류·세부분류 이름을 `/`로 이어 붙여 합칩니다. 행 우클릭 또는 오른쪽 메뉴의 **분리하기**로 합치기 전 행을 복원하며, 일반 행을 분리하면 새 분류를 입력할 행이 추가됩니다. 메뉴의 **다른 행과 합치기**는 드래그 대신 사용할 수 있습니다. 합친 이름과 기준도 셀에서 바로 고칩니다. **되돌리기**로 조작을 취소하고 **분류 기준표 저장**으로 새 버전을 확정합니다. 이름만 입력한 새 행의 빈 기준은 저장할 때 AI가 보완합니다. **이 기준표로 VOC 분류하기**를 누르면 저장한 기준표로 고객 의견을 분석해 결과를 보여줍니다.

기존 기준을 전반적으로 다시 만들려면 표 바로 아래 **분류 기준표 새로 만들기**를 펼칩니다. 수정값 유지 선택과 저장·분류 실행 버튼은 이 영역 아래에 있습니다. **자료 설명과 분류 요청 (선택)**에 상황과 원하는 분류 방향을 적고 **AI로 새 분류 기준표 만들기**를 누르면 별도의 새 초안을 만듭니다. 예: `자동차 구매 과정의 만족도 조사입니다. 영업사원 응대, 계약 절차, 차량 인도 경험을 중심으로 분류해주세요.`

기준표 버전 드롭다운을 펼치면 각 줄에서 **수정 표시**로 이름을 직접 입력하고 Enter 또는 저장 표시로 저장할 수 있습니다. **×**로 해당 기준표를 목록에서 제거합니다. 이름은 버전·초안/확정 상태와 함께 표시합니다. 선택하지 않은 기준표를 수정·삭제해도 현재 선택을 유지하며, 선택한 기준표 삭제 시 남은 최신 기준표로 전환합니다. 마지막 기준표를 삭제하면 새 초안 생성 화면으로 돌아갑니다. 이미 만든 분류 결과와 수정 승계에 필요한 기준표 기록은 보존하며, 분류 진행 중인 기준표는 삭제할 수 없습니다.

배운 **작업 의존성과 순차 진행**을 적용해, 저장된 원문이 분류 기준표의 근거가 되고 확정한 분류 기준표가 분류의 기준이 되게 했습니다. 화면에서 같은 VOC ID의 원문·분류 기준·여러 의견을 따라가며 이 연결을 확인할 수 있습니다.

## 저장된 입력 자료 관리

**분류 기준표**와 **분류 결과** 상단의 **저장된 입력 자료**를 펼쳐 각 자료를 선택하거나 관리합니다. 입력 화면에는 자료 목록을 표시하지 않습니다. 목록 폭은 선택 버튼과 같고 긴 제목은 말줄임으로 표시합니다. 중복 제목은 날짜 대신 `새 VOC 분석 1`, `새 VOC 분석 2`처럼 번호로 구분합니다.

- 연필 표시를 누르면 해당 줄에서 이름을 바꿀 수 있습니다. Enter 또는 체크 표시로 저장합니다. 드롭다운을 닫거나 다른 자료를 선택하면 저장하지 않은 편집은 취소합니다.
- ×를 누르면 확인 창 없이 해당 자료가 바로 삭제됩니다. 원문·분류 기준표·분석 결과·수정 이력·저장 묶음도 함께 삭제되며 복구할 수 없습니다. 분류 진행 중에는 ×가 비활성화됩니다.
- 다른 자료를 수정·삭제해도 현재 보고 있는 자료는 유지됩니다. 선택한 자료를 삭제하면 남은 자료로 전환하고, 마지막 자료를 삭제하면 입력 화면으로 돌아갑니다.

배운 **상태·산출물 관리**를 적용해 항목 ID에 연결된 입력과 분석 정보를 함께 정리합니다. 직접 확인할 결과는 해당 줄에서 이름이 바뀌고 × 삭제 후 항목이 사라지며 다른 자료의 결과는 유지되는 것입니다. 자료 관리에는 AI를 호출하지 않습니다.

## 분류 결과 확인과 원문 탐색

**3. 분류 결과**는 **감성 → 대분류 → 세부분류 → 원문** 순서로 탐색합니다. 기본·감성 선택·대분류 선택 상태에서 차트를 같은 화면에 유지합니다.

1. 감성을 선택하면 두 차트가 해당 감성의 응답으로 바뀝니다. **대분류**를 누르면 오른쪽 세부분류만 좁혀지고, **세부분류**를 누르면 해당 원문 팝업이 열립니다. 대분류의 원문은 행 메뉴에서 바로 열 수 있습니다. 같은 감성·대분류 재클릭 또는 조건의 ×로 해제하며 **조건 전체 해제**도 제공합니다. 감성을 바꾸면 대분류 선택은 해제됩니다. 하단 **현재 조건 원문 보기**는 현재 감성·대분류 안의 원문을 열고, 조건이 없으면 **전체 원문 보기**로 표시합니다. 차트에서 합친 묶음은 조건을 해제해도 유지됩니다.
2. 표의 **원문·분류·감성·응답 상태** 열 제목을 눌러 엑셀 자동 필터처럼 여러 값을 체크하고 **적용**합니다. 원문 포함 검색은 **원문** 열 메뉴에서 입력합니다. 같은 열의 선택은 OR, 서로 다른 열의 조건은 AND로 적용하며 **해제**는 해당 열의 조건만 지웁니다. 응답 상태는 맨 오른쪽 좁은 열에 표시합니다. **전체 보기**는 분류·검색·필터와 응답 선택을 초기화합니다. 기본 목록에는 내용 없는 응답·검토 필요·실패·미처리도 포함합니다. ×·Esc·바깥 클릭으로 닫을 수 있습니다.
3. **분류·감성 셀을 더블클릭 → 드롭다운에서 선택 → 저장**으로 바로 수정합니다. 감성은 **긍정·부정·중립·판단 불가** 중 고릅니다. 의견이 여러 개면 분류·근거를 보고 각각 고릅니다. Enter·F2와 터치도 지원하며 **취소**·Esc·바깥 클릭은 변경을 버립니다. 일반 원문 행을 선택하면 별도 응답 상세 대신 그래프 아래 맨 하단의 **수정 이력**을 필요할 때 펼쳐봅니다. 기본은 접힘이며 최초 분류와 변경 내역을 보존합니다. 표에서 수정할 수 없는 검토·분류 미지정·내용 없는 응답은 기존 확인·수정 경로를 유지합니다.
4. 그래프 아래 **다운로드** 메뉴에서 **VOC별 분류 다운로드**, **분류 통계 다운로드**를 선택해 Excel 파일을 받습니다. VOC별 파일은 **VOC ID·VOC 원문·대분류·세부분류·감성**을 담고, 여러 분류가 있는 VOC는 같은 ID의 여러 행으로 표시합니다. 같은 분류·감성의 반복 근거는 한 행으로 정리하고 분류되지 않은 원문은 빈 분류·감성으로 포함합니다. 통계 파일은 **대분류·세부분류 시트**를 나누며 **전체 건수·%·긍정 (%)·부정 (%)·혼합 (%)·무응답/중립/미검토 (%)**를 담습니다. 두 파일은 감성·대분류·팝업 필터와 표시 개수 제한 없이 전체 응답을 사용하며 팝업 안의 다운로드 메뉴는 표시하지 않습니다. 저장·불러오기·되돌리기는 옆의 **지금 분류 저장** 메뉴에 모았습니다.

기본 분류 그래프는 무응답 포함 전체 원본 응답을 분모로 사용하고, 상단 감성을 선택하면 그 감성의 응답 수를 기준으로 다시 계산합니다. 원문 팝업의 조건은 첫 화면 그래프의 분모를 바꾸지 않습니다. 다운로드와 팝업의 전체 대비 비율은 전체 원본 응답을 기준으로 유지됩니다. 통계 파일은 현재 그래프의 묶음을 반영합니다. 예를 들어 배송 속도와 오배송을 합치면 세부분류 시트에 **배송 속도/오배송** 한 행으로 표시하며 같은 VOC를 중복 없이 셉니다. 합치기를 되돌리면 다운로드도 원래 분류별 행으로 돌아갑니다. 통계 파일의 **%**는 전체 원본 응답 대비 비율이고 감성별 비율은 해당 분류의 고유 응답 수를 분모로 사용합니다. 한 응답에 여러 분류가 있으므로 분류별 %의 합은 100%를 넘을 수 있지만, 각 분류의 감성 비율은 긍정·부정·혼합·무응답/중립/미검토로 나눠 100%가 됩니다. 팝업 안의 상세 집계는 표의 필터를 적용합니다. 내용 없는 응답에는 감성을 부여하지 않습니다.

첫 화면 맨 위에는 전체 응답의 **감성 비중** 가로 누적 막대를, 그 아래에는 대분류·세부분류를 표시합니다. 막대 구간이나 범례를 누르면 팝업 없이 두 분류 그래프를 해당 감성의 응답 기준으로 재편성합니다. 다른 감성은 옅게 표시하고 선택한 범례를 강조하며, 같은 감성을 다시 누르면 전체 그래프로 돌아갑니다. 혼합 응답은 긍정·부정에 중복 포함하지 않고 선택된 VOC의 전체 분류를 함께 집계합니다. 선택 후 분류 그래프를 클릭하면 해당 감성과 분류에 맞는 원문만 조회합니다. 팝업의 **전체 보기**·닫기와 분류 합치기는 상단 감성 선택을 유지합니다. 상단 막대의 전체 비중은 유지하고 감성 수정은 최신 결과로 반영합니다. 전체 원문 팝업은 시각화나 집계표 없이 원문 조회·표 직접 수정·수정 이력을 제공합니다.

대분류를 눌러 연 팝업의 **분류·감성 비중**은 그래프로 표시합니다. 세부분류마다 진한 막대의 **전체 응답 대비 비율**과 연한 부분까지의 **대분류 내 비율**을 한 줄에서 비교합니다. 두 비율을 더하지 않습니다. 전체 대비 비율은 진한 막대 안 오른쪽 끝에 흰색으로, 대분류 내 비율은 전체 막대 끝 바깥에 표시합니다. **감성 비중** 원그래프는 한 VOC를 한 번씩 세고 긍정·부정이 함께 있으면 **혼합**으로 표시해 합계가 100%가 됩니다. 무응답·중립·판단 불가·검토·미처리는 **무응답/중립/미검토** 한 항목으로 합쳐 표시합니다. 숫자는 비율만 표시하며 응답 수와 전체 사례수는 그래프에 마우스를 올리거나 터치해 확인합니다. 현재 열 필터를 적용하고, 빈 결과에는 필터를 해제하는 안내를 제공합니다. 세부분류 팝업은 집계표 대신 **감성 비중** 원그래프만 바로 보여주며, 해당 세부분류 또는 합친 묶음의 의견만 집계합니다.

원문 표와 감성 필터에서는 감성값 없는 **—**를 **중립**으로 합쳐 표시합니다. **중립** 필터는 중립 의견과 감성값 없는 응답을 함께 조회하며 **판단 불가**는 별도 항목으로 유지합니다. 무응답·검토·실패·미처리는 응답 상태 열에서 구분하고 원래 의견 감성과 응답 상태는 보존합니다.

그래프 오른쪽 끝의 **표시할 분류 수**에서 **전체·5·10·20·50** 중 하나를 고릅니다. 기본값인 **전체**는 개수 제한 없이 모든 분류를 표시합니다. 막대 옆에는 건수와 전체 응답 대비 비율을 함께 표시합니다. TOP N의 마지막 순위와 건수가 같은 분류는 모두 표시하고 동률 안내를 붙입니다. 전체 집계표와 원문·다운로드에서 나머지 분류를 제외하지 않습니다. 미완료 실행은 잠정 원문 결과를 제공하며 분류·검토가 끝나기 전에는 완료 차트를 표시하지 않습니다.

배운 **Workflow와 지표의 집계 단위·분자·분모**를 적용해 분포 확인에서 원문 조회·수정까지 연결하고 전체 분포와 현재 원문 범위의 비율을 구분했습니다. 직접 확인할 결과는 분류 막대 선택 후 원문만 좁혀지고, 선택한 응답의 수정 결과가 목록·집계·CSV에 반영되는 것입니다.

## 분류 합쳐 보기

차트 행 왼쪽 손잡이를 같은 차트의 다른 행에 끌어 놓으면 이름을 `/`로 이어 한 막대로 합칩니다. 오른쪽 메뉴에서 대상 분류를 선택해도 같습니다. 대분류·세부분류의 묶음은 각각 관리하며 다른 차트 사이에는 합치지 않습니다. **합치기 되돌리기**로 직전 조작을 취소합니다.

합친 막대를 누르면 해당 범위의 원문 팝업이 열립니다. 대분류 묶음은 그 아래 원래 세부분류를 모두 포함합니다. 분류를 합친 뒤 그래프 아래의 **지금 분류 저장**에서 저장할 분류를 확인하고 이름을 입력합니다. 감성은 고르지 않으며 현재 감성 필터는 새 저장에 포함하지 않습니다. 같은 그래프 영역의 **저장한 분류 → 불러올 분류 → 불러오기**로 세부분류 묶음과 원문 범위를 복원합니다. 목록 각 줄 오른쪽의 연필로 이름을 수정하고 Enter 또는 저장 표시로 반영하며, ×로 저장 항목을 삭제합니다. 이름 수정·삭제는 현재 차트 묶음과 원래 분류 결과를 변경하지 않습니다. 고객 원문 팝업의 검색·열 필터는 저장 조건으로 사용하지 않습니다. 저장하지 않은 차트 묶음은 현재 브라우저의 실행별 보기 상태입니다.

분류 간 겹치는 원문은 VOC ID 기준으로 한 번만 셉니다. 같은 본문이어도 서로 다른 입력 행이면 별개 응답입니다. 합친 차트·상세 집계·통계 Excel에는 같은 묶음이 반영되고, VOC별 Excel에는 원래 분류·감성이 보존됩니다. 조회·합치기·되돌리기·묶음 저장·개별 수정은 AI 재호출 없이 동작합니다. 새 기준에 따라 원문을 나누는 기능은 결과 화면에 추가하지 않았으며 기준을 바꾸고 다시 분류하는 작업은 분류 기준표에서 실행합니다.

## 개별 결과 수정과 변경된 기준으로 다시 분류

분류만 바꾸려면 **3. 분류 결과**의 **분류 셀을 더블클릭**해 의견별 드롭다운에서 고르고 **저장**합니다. 기존 원문·근거·감성과 필터에서 숨긴 의견을 유지하며 이력에는 ‘표에서 분류 변경’으로 기록합니다. 현재 결과·차트·CSV에 반영되고 AI 최초 결과는 보존합니다. 검토 중인 변경·처리 실패·내용 없는 응답은 이 조작으로 확정하지 않습니다.

감성만 바꾸려면 **감성 셀을 더블클릭**해 의견별 드롭다운에서 고르고 **저장**합니다. 세부분류 팝업에서는 선택한 세부분류의 감성만 수정하며, 합친 세부분류는 묶음에 포함된 의견을 수정합니다. 분류·원문 근거·다른 분류의 감성을 유지하며 이력에는 ‘표에서 감성 변경’으로 기록합니다. 표·감성 그래프·다운로드 파일에 바로 반영되고 AI 최초 결과는 보존합니다.

표에서 직접 수정할 수 있는 응답은 체크박스나 원문 행을 선택해 그래프 아래의 **수정 이력**만 조회합니다. 별도의 응답 상세와 중복된 **이 응답 수정** 버튼은 표시하지 않습니다. 표에서 수정할 수 없는 검토·분류 미지정·내용 없는 응답은 기존 상세의 확인·수정 경로를 사용합니다. 수정 이유를 적고 저장하며 **편집 취소**는 저장 전 변경을 버립니다.

**2. 분류 기준표**의 표에서 이름·대분류·기준·행을 편집하거나 행을 합치고 나눈 뒤 **분류 기준표 저장**으로 새 버전을 만듭니다. 서로 다른 의미를 합쳐 조회할 때는 결과 화면의 묶어보기를 사용합니다.

**통합·분리의 분류 기준은 선택 입력**입니다. 이름만 적고 저장하면 AI가 기존 분류 기준표·분석 배경·원문 표본을 참고해 빈 기준만 채워 새 버전으로 저장합니다. 직접 쓴 기준과 대분류·이름은 그대로 유지합니다. 생성에 실패하면 입력 내용을 유지하고 기존 버전을 보존하므로 재시도할 수 있습니다. AI 자동 생성에는 설치 시 저장한 Gemini API 키가 필요하며, 기준을 모두 직접 입력하면 AI 호출 없이 저장합니다.

새 버전 저장 후 **이 기준표로 VOC 분류하기**를 누릅니다. 같은 입력 자료에서 현재 기준표와 그 이전 버전으로 완료한 최근 분석을 자동 연결합니다. 이어받을 수정이 있을 때만 **직접 수정한 분류 결과 유지**가 기본 체크 상태로 나타납니다. 전체 원문을 AI가 재평가한 뒤 사용자가 바꾼 항목만 승계합니다. 체크를 해제하면 이전 수정 없이 새로 분류하며, 그 분석을 완료한 뒤에는 더 오래된 수정이 다시 적용되지 않습니다. 다른 자료·다른 갈래의 기준표로 만든 분석은 자동 연결하지 않습니다.

실행을 시작할 때 연결된 이전 분석과 수정 개정 번호를 고정하므로 이후에 바꾼 수정이 진행 중인 분석에 섞이지 않습니다. AI로 별도의 새 기준표를 생성하면 기존 버전과의 대응 관계가 없으므로 자동 승계 없이 시작합니다.

| 변경 상황 | 처리 |
| --- | --- |
| 관련 코드 유지·이름 변경·무관한 코드 변경 | 사용자 변경을 자동 반영하고 수정하지 않은 의견은 새 AI 제안 사용 |
| 같은 의미 코드 통합 | 명시적으로 저장한 이전 코드→새 코드 대응 사용 |
| 분리·삭제·정의 변경·근거 대응 불명확·사용한 배경 근거 삭제 | 해당 VOC를 승계 검토로 남기고 AI 후보를 완료 집계에서 제외 |

검토가 남으면 결과 화면의 **확인이 필요한 응답 N건 보기**에서 원문을 선택하고 **확인·수정**으로 이전 수정과 새 분류 결과를 비교한 뒤 **확인하고 저장**을 누릅니다. 모든 미해결 건이 해소돼야 완료가 됩니다. 처음 결과 화면을 열 때는 이전 완료 실행이 기본이며 저장된 실행 선택으로 검토 중인 새 실행도 볼 수 있습니다.

배운 **상태·산출물 관리와 완료 조건**을 적용해 AI 최초 결과, 현재 수정본, 원래 수정 출처와 버전 이력을 구분했습니다. 직접 확인할 결과는 수정 후 같은 원문의 AI 최초 값이 보존되고, 표·묶음·다운로드에는 현재 값이 일관되게 나타나는 것입니다. 기준을 직접 입력한 분류 기준표 수정과 개별 결과 수정은 AI를 호출하지 않습니다. 통합·분리에서 빈 기준을 생성하는 경우에는 AI를 호출하며, 전체 VOC의 재평가는 전체 분류 버튼으로 시작합니다.

## Gemini 설정

로컬에서는 프로젝트 최상위 `.env`에 `GEMINI_API_KEY=본인의키`를 저장합니다. 처음에는 `.env.example`을 복사해서 사용합니다. 화면에는 키를 표시하지 않으며 전역 환경 변수의 키를 가져오지 않습니다. `.env`가 없을 때만 아래에서 명시적으로 활성화한 Streamlit Secrets를 사용합니다.

### 발표용 Streamlit Community Cloud 배포

1. Community Cloud에서 `Kimminsun8220/VOC-Analyzer`, 배포할 브랜치, 실행 파일 `app.py`를 선택합니다.
2. Advanced settings에서 Python 3.14를 선택합니다. 로컬에서 확인한 버전이며 배포 환경의 설치 결과도 확인해야 합니다.
3. Secrets에 아래 설정을 넣고 실제 키는 관리 화면에서만 입력합니다. 비밀 값은 Git에 커밋하지 않습니다.

```toml
ENABLE_CLOUD_SECRETS = true
GEMINI_API_KEY = "발표용 API 키"
```

## 처리 규칙

- 파일 최대 10MB, 응답 최대 500행, 본문당 최대 5,000자, 공통 배경 최대 10,000자입니다. 초과하면 알리고 임의로 원문을 자르지 않습니다.
- 붙여넣기는 빈 줄을 제외한 한 줄을 한 건으로 읽습니다. CSV 형식상의 빈 줄도 제외합니다. CSV의 빈 셀·따옴표로 표현된 빈 응답, XLSX에서 ID 등 행 정보가 있는 빈 응답은 무응답으로 보존합니다. 중복 본문은 각각 다른 VOC입니다.
- 초안은 최대 100건·합계 60,000자 표본으로 생성합니다. 실제 표본 ID를 저장합니다. 전체 분류는 최대 10건·합계 20,000자씩 진행합니다.
- 한 VOC의 모든 의견과 감성을 각각 보존합니다. 긍정·부정이 함께 있으면 원문 전체 감성은 혼합입니다. 내용 없는 응답에는 감성을 부여하지 않습니다. 특정 역할이 없는 직원·담당자는 역할 미상으로 표시합니다.
- 기존 코드에 없는 의미는 근거와 함께 자동 보완하고 **전체 VOC를 새 분류 기준표로 다시 분류**합니다. 한 실행 요청에서 기본 최대 2회 보완하며 미해결 건을 완료로 표시하지 않습니다. 검토 후 보완을 최대 2회씩 더 실행할 수 있습니다.
- 의미 중복과 사용자 편집 의도는 AI에 비교를 요청하고, 동일 이름·정의 및 삭제·변경한 기존 정의의 재추가는 코드로도 차단합니다. 의미만 바꿔 쓴 중복이나 편집 충돌의 완전한 방지는 실제 자료로 추가 검증해야 합니다.
- 배경을 바꾸면 새 분류 기준표를 생성합니다. 이전 분류 기준표·실행의 배경과 결과는 그대로 남습니다.

## 저장·오류 복구

입력, 메타데이터, 분류 기준표 버전, 표본 ID, 자동 추가 근거, 실행별 배경·모델·프롬프트 버전과 AI 결과·수정 이력·승계 기준·묶음을 `data/voc_analyzer.db`에 저장합니다. 기존 DB에는 필요한 표·열만 추가하며 이전 자료를 유지합니다. 앱을 재시작하면 분류 기준표·분류 결과 상단의 **저장된 입력 자료**와 결과 화면의 **저장된 분석 실행**에서 다시 열 수 있습니다. 원문이 포함된 로컬 DB와 `.local/` 검증 기록은 Git에서 제외합니다.

요청 한도·연결·응답 형식 오류는 제한적으로 재시도합니다. 근거·ID 검증에 실패한 VOC는 전체 의견 목록을 성공 결과에서 제외합니다. **실패·미처리 이어서 실행**은 성공 건을 보존하고 필요한 건만 재처리합니다. 자동 보완 시에는 새 회차에 전체 결과를 저장하고 이전 회차를 남깁니다. 진행 중 중단된 실행은 잠금이 만료되는 최대 6분 후 재개할 수 있습니다. 백그라운드 작업 서버는 아닙니다.

## 코드를 읽는 순서

- `src/ingestion.py`: 원문·빈 응답·행 식별자 준비
- `src/models.py`: 코드·의견·근거의 구조와 검증
- `src/storage.py`: SQLite에 버전과 실행 저장
- `src/ai.py`: Gemini 요청·프롬프트·제한 재시도
- `src/workflow.py`: 분류 기준표 확정, 분류, 자동 보완과 재개
- `src/results.py`: 원본 응답과 의견별 표·안전한 CSV 사본
- `src/grouping.py`: 선택한 분류의 고유 VOC 집계와 원문 연결
- `src/grouping_ui.py`: 원문 팝업·응답 선택·필터·조합 저장/불러오기·CSV
- `src/result_explorer.py`: 열 필터·원문 조건·내보내기 범위 일치
- `src/response_table.py`, `src/components/response_table.*`: 열 제목 자동 필터·원문 행 선택·분류·감성 셀 직접 수정
- `src/result_downloads.py`: 전체 VOC별 분류와 대분류·세부분류 통계 Excel 생성
- `src/chart_data.py`: 고유 VOC 기준 차트 집계·분모·선택 범위·집계 CSV
- `src/charts_ui.py`: 대분류·세부분류 동시 분포·드래그 합치기·공통 설정·원문 팝업
- `src/result_groups.py`: 실행별 차트 묶음·고유 응답 집계·되돌리기·조작 유효성·집계 CSV
- `src/codebook_changes.py`: 분류 기준표 변경·통합·분리와 명시적 버전 대응
- `src/corrections.py`: 원문 구간·변경 전후 기록, 수정 저장·승계·검토
- `src/codebook_ui.py`, `src/corrections_ui.py`: 새 버전 편집과 개별 수정·검토 화면
- `app.py`: 세 단계 화면과 사용자 동작 연결

전체 기능 기준은 [PRD.md](./PRD.md), 계획과 진행 상황은 [plan.md](./plan.md), 결정과 학습 적용 기록은 [Learning.md](./Learning.md)에 있습니다. 화면 디자인과 UI 문구를 수정하기 전에는 [design.md](./design.md)를 읽습니다.

가격·할인처럼 구체적인 평가 근거가 있는 의견은 해당 주제로 분류합니다. 전반적 만족도는 대상이 특정되지 않은 종합 평가에 한정하며, 명시적인 가격 근거를 일반 만족도로 배정하는 알려진 오류는 검증에서 차단합니다. 조건부 감수와 명시적인 만족을 구분합니다.


### 코드북 품질 비교

기존 실행을 읽어 별도 `.local/` DB에서 생성·품질 검토·분류를 비교합니다. API 실행에는 `--execute`가 필요합니다. 기존 DB와 수정 이력은 변경하지 않습니다.

```powershell
.venv\Scripts\python.exe scripts/evaluate_codebook_quality.py --source-run <실행_ID> --execute
```

비교 JSON은 코드 수·명시적 이름 중복·포함/제외 정의·한 응답만 배정된 코드·기타 고유 VOC 비중·미해결 응답·8항목 AI 검토를 담습니다. 코드 수 감소나 기타 비중 감소만으로 개선을 판정하지 않고 원문 대비 누락·경계·과세분화도 검토해야 합니다. 저장된 수정 결과와 새 AI 결과의 비교이므로 동일 조건의 정확도 실험이나 리코딩 감소의 장기 측정은 아닙니다.
